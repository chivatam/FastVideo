# SparseFP4 Video Attention — 10-prompt DEVELOPMENT set (text-to-video).
#
# This is the DEVELOPMENT set used for Phase 1/2 activation and error studies
# and for the Phase 5 smoke-scale end-to-end runs. It is NOT a benchmark set.
# Per SKILL.md ("Do not claim benchmark-wide superiority from the 10-prompt
# development set") and integrity rule 10, any result computed on these prompts
# must be reported as a development-set result, and the report must disclose that
# the set was used while developing the method.
#
# Format: one prompt per line. Lines starting with '#' and blank lines are
# comments and are skipped. prompt_id is assigned by position over the
# non-comment lines: p01 .. p10, in the order below. Do not reorder, insert, or
# delete lines once a run has been recorded — prompt_id is used as a join key in
# artifacts/sparsefp4/raw/<run_id>/*.jsonl.
#
# Provenance: every prompt is reused verbatim from an existing FastVideo asset so
# that these runs stay comparable to the repo's own examples/tests.
#   p01, p05  examples/inference/basic/basic.py
#   p02       fastvideo/tests/ssim/test_wan_t2v_similarity.py (WAN_T2V_TEST_PROMPTS)
#   p03       examples/inference/basic/basic_dmd.py
#   p04       examples/inference/basic/basic_turbodiffusion_i2v.py
#             (also examples/inference/optimizations/text_encoder_quant_example.py)
#   p06       examples/inference/basic/basic_gamecraft.py
#   p07, p09, p10  assets/prompts/mixkit_i2v.jsonl (prompt field only; the
#             companion image_path is ignored — these are used as T2V prompts)
#   p08       examples/distill/Wan2.1-T2V/Wan-Syn-Data-480P/validation_64.json
#
# Content coverage — deliberately spread so that Phase 1/2 routing sensitivity is
# not confounded with a single content type (an all-static or all-aerial set
# would make block-sparse routing look artificially stable or unstable):
#   p01  motion-heavy subject + steady tracking camera
#   p02  motion-heavy human action, busy background, mid-shot
#   p03  multi-object + heavy texture/reflection detail, night, rain
#   p04  near-static close-up subject, shallow depth of field
#   p05  near-static subject, dense repeated texture (petals)
#   p06  static scene, rigid geometric structure
#   p07  camera motion (aerial drone push), static content
#   p08  static scene, low-motion atmospheric texture (mist, haze)
#   p09  camera motion (aerial tour) + small independent movers (birds)
#   p10  multi-object / multi-agent scene with background motion
#
# Paper-scale upgrade path: if the results justify it, replace this set with a
# 50-100 prompt VBench-compatible set (per SKILL.md Phase 5), keeping the same
# line-per-prompt format and the same pN id scheme so the harness and
# scripts/analyze_masks.py need no changes; point
# `prompt_set.paper_scale` in assets/experiment_config.yaml at that file and keep
# this set as the declared development set. Choose VBench prompts from the
# dimensions relevant to temporal generation (subject/background consistency,
# motion smoothness, dynamic degree, aesthetic and imaging quality) so per-prompt
# scores are directly comparable to published VBench numbers; do not hand-pick
# prompts after seeing sparse-attention results.
